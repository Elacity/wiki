## VerifierModule

Verifies license requests signed with EIP-712 typed data.

_Uses generated encoder/recovery helpers from `EIP712Decoder`.

`EIP712Decoder` contract is generated by [eip712-codegen](https://github.com/danfinlay/eip712-codegen)
check the [readme file](https://github.com/danfinlay/eip712-codegen#readme)

`./node_modules/.bin/712gen ./typedData.js | sed "s/0.8.13/0.8.20/g" > contracts/modules/utils/TypedDataDecoder.sol`_

### __VerifierModule_init

```solidity
function __VerifierModule_init(string contractName, string version) internal
```

Initializes domain parameters used for EIP-712 verification.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| contractName | string | Name used in the EIP-712 domain. |
| version | string | Protocol version string used in the domain. |

### verifyLicenseRequest

| Name | Type | Description |
| ---- | ---- | ----------- |

| Name | Type | Description |

| [0] | address | signer Recovered signer address. |
