## IERC5501

the EIP-165 identifier for this interface is 0xf808ec37.

_see https://eips.ethereum.org/EIPS/eip-5501_

### UpdateUser

```solidity
event UpdateUser(uint256 _tokenId, address _user, uint64 _expires, bool _isBorrowed)
```

_Emitted when the user of an NFT is modified._

### setUser

```solidity
function setUser(uint256 _tokenId, address _user, uint64 _expires, bool _isBorrowed) external
```

Set the user info of an NFT.

_User address cannot be zero address.
Only approved operator or NFT owner can set the user.
If NFT is borrowed, the user info cannot be changed until user status expires._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| _tokenId | uint256 | uint256 ID of the token to set user info for |
| _user | address | address of the new user |
| _expires | uint64 | Unix timestamp when user info expires |
| _isBorrowed | bool | flag whether or not the NFT is borrowed |
