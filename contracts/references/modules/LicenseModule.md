## LicenseModule

Abstract module providing core licensing capabilities for Digital Assets within the DRM ecosystem.

_Handles license issuance, access checks over operatives, and EIP-712 based license requests.
`EIP712Decoder` contract is generated by eip712-codegen
check on https://github.com/danfinlay/eip712-codegen#readme
`./node_modules/.bin/712gen ./typedData.js | sed "s/0.8.13/0.8.12/g" > contracts/modules/utils/TypedDataDecoder.sol`_

### InvalidSignature

```solidity
error InvalidSignature(address accessor, address signer)
```

Thrown when a license request signature does not match the expected signer.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| accessor | address | The address of the user or system acquiring the license. |
| signer | address | The recovered/declared signer that failed validation. |

### _requestUserAccess

```solidity
function _requestUserAccess(contract IStorage store, address accessor, address ledger, uint256 tokenId) internal view returns (bool haveAccess, uint256[] entitlements)
```

Check the access to a given Digital Asset.

_This will check over Operative contract in order to detect if a user have token(s) that allows to access the asset._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| store | contract IStorage | The storage contract used to locate the operator for a ledger/token. |
| accessor | address | The address of the user seeking access. |
| ledger | address | The address of the ledger contract hosting the digital asset. |
| tokenId | uint256 | The unique token ID within the ledger. |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| haveAccess | bool | A boolean indicating if the accessor has the right to access. |
| entitlements | uint256[] | An array of entitlements granted to the accessor. |

### _acquireLicense

```solidity
function _acquireLicense(contract IStorage store, bytes payload) internal view returns (bytes4, bytes)
```

Processes a license request, verifying signatures and checking access rights before issuing.

_Unwraps an EIP-712 LicenseRequest payload, confirms signature, verifies operative access, and issues license._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| store | contract IStorage | The storage contract to query for operator assignment. |
| payload | bytes | The encoded license request payload. |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | bytes4 | cs The callback selector configured by the handler. |
| [1] | bytes | A tuple containing the response payload with the enclosed license. |

### registerIPWithKey


| ---- | ---- | ----------- |

| _contentId | bytes16 | The content id of the asset |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | bytes32 | The hash of the newly registered IP entity and the key provided. |
| [1] | bytes |  |
