## VerifierModule

This is the core module in charge of verifying license requests
It complies with [EIP-721](https://eips.ethereum.org/EIPS/eip-712) data structure
to produce and verify signatures

_`EIP712Decoder` contract is generated by [eip712-codegen](https://github.com/danfinlay/eip712-codegen)
check the [readme file](https://github.com/danfinlay/eip712-codegen#readme)

`./node_modules/.bin/712gen ./typedData.js | sed "s/0.8.13/0.8.20/g" > contracts/modules/utils/TypedDataDecoder.sol`_

### verifyLicenseRequest

```solidity
function verifyLicenseRequest(struct LicenseRequest lr, bytes sig) public view returns (address)
```

_verify gueniness of a request
It's a public methdod used by `acquireLicense` but could be use externally for verification purpose.
This flow is a verification step ahead of the ECDSA Signature Verification
It returns an address that should be equal to the signer address_

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| lr | struct LicenseRequest | LicenseRequest |
| sig | bytes | bytes signature |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | address | signer address |
