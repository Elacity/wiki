# Information Architecture

This page defines the intended boundary of each GitBook space in the ElacityLabs docs site.

## Spaces

### Home

- Purpose: top-level orientation and site map.
- Audience: all users arriving on the docs site.

### Documentation

- Purpose: implementation guides and SDK usage.
- Audience: developers and integrators building with Elacity SDKs and services.

### API Reference

- Purpose: endpoint-centric API reference and request/response semantics.
- Audience: API integrators and backend/frontend engineers.

### Protocol v3.0

- Purpose: current smart-contract architecture and references.
- Audience: protocol integrators, smart-contract developers, auditors.

### Protocol v2.0

- Purpose: legacy protocol reference for migration and compatibility checks.
- Audience: teams maintaining v2 integrations.

### Changelog

- Purpose: release notes and notable changes across products/spaces.
- Audience: all consumers tracking updates.

### Help Center

- Purpose: troubleshooting and support guidance.
- Audience: users needing issue resolution paths.

## Protocol Variants

The docs site exposes protocol docs as a variant group:

- Variant `v3.0`: active/current architecture.
- Variant `v2.0`: legacy/archive reference.

Variant pages should keep comparable section topology (`getting-started`, `technical`, `references`) where possible to simplify navigation.
