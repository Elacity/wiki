# Documentation Feedback

Use this page when the docs are unclear, outdated, or inconsistent.

## What To Include

- Page URL/path.
- Current wording/snippet.
- Why it is confusing or incorrect.
- Suggested replacement text (if available).
- Protocol/SDK version context.

## Feedback Categories

- Accuracy issue (factually wrong/outdated).
- Navigation issue (hard to find content).
- Completeness gap (missing critical integration detail).
- Terminology mismatch (SDK vs contract naming).
