# Help Center

Use this space to resolve integration blockers quickly and route issues to the right channel.

## In This Space

- Getting support paths and issue-routing guidance.
- Documentation feedback workflow.
- Frequently asked questions.

## Before Opening a Support Request

- Check relevant package docs in the `Documentation` space.
- Confirm protocol version (`v3.0` vs `v2.0`) for contract-related issues.
- Collect reproducible context: chain, environment, SDK version, and error output.
