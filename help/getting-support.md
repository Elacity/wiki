# Getting Support

Use this guide to route issues to the right documentation surface quickly.

## 1. Identify the scope

- SDK/API usage issue: start in `Documentation`.
- Smart-contract behavior issue: check `Protocol v3.0` (or `v2.0` for legacy).
- Endpoint payload/response issue: use `API Reference`.

## 2. Gather minimum context

- Product/package name.
- Environment (browser/server), chain, and network.
- SDK version or commit SHA.
- Repro steps and observed vs expected behavior.

## 3. Escalation path

- Documentation mismatch: file a docs feedback item.
- Runtime/product bug: escalate to engineering with repro details.
- Access/account issues: route through standard support operations.
