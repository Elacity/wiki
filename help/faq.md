# FAQ

## Which protocol version should I use?

Use `Protocol v3.0` for current integrations. Use `v2.0` only for legacy compatibility and migration support.

## Where do I find SDK usage examples?

See the `Documentation` space, especially package-specific sections (`api`, `contracts`, `media-player`, `media-packager`).

## Where is the source of truth for contract behavior?

For protocol behavior, the Solidity contracts and references in the protocol spaces are authoritative.

## I found conflicting docs. What should I do?

Open a documentation feedback item with both page paths and the conflicting statements.
